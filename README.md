# EscapeX
A browser-based maze escape game featuring progressively challenging level, BFS-based hunter AI, dynamic gameplay, and a cinematic user interface.


**EscapeX**
  EscapeX is a browser-based maze escape game where players must navigate through increasingly challenging levels while avoiding a hunter powered by the **Breadth-First Search(BFS)** **pathfinding algorithm.**

  The project combines **_game development, artificial intelligence, pathfinding algorithms, Python backend logic, and a modern web-based fronted_** into an interact gaming experience.
